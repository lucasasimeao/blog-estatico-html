# Blog Estático em HTML (exercício)

> Exercício de HTML com duas páginas ligadas por navegação, feito para praticar caminhos relativos e organização de pastas.

![HTML5](https://img.shields.io/badge/HTML5-E34F26?logo=html5&logoColor=white)

## Sobre

Mini site de blog com página inicial e página "Sobre". Exercício de aprendizado de HTML.

## O que foi praticado

- Várias páginas em pastas diferentes (`index.html` e `sobre/index.html`)
- Navegação com links relativos (`sobre/index.html` e `../index.html`)
- Imagens em pasta separada (`images/`)

## Como ver

Abra `index.html` no navegador.

## Estrutura

```text
.
├── index.html
├── sobre/index.html
└── images/
```
